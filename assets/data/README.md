# Surah metadata

Phase 2 will add `surahs.json` here with all 114 Surahs.

Each entry will include:

- Surah number
- Arabic name
- English transliteration
- English meaning
- Ayah count
- Revelation place (Makki/Madani)
- Local audio asset path
- Sample-audio flag

The data will be validated by tests for exactly 114 entries, sequential
numbering, correct total ayah count, and existing audio paths.
